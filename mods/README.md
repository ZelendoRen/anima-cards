# Mod cards

One folder per plugin file, named exactly like the plugin: `mods/3DNPC.esp/`, `mods/Immersive Wenches.esp/` ...
Each NPC of that mod is one JSON file in it. ANIMA downloads a folder only for players who have that plugin installed,
and a card here replaces the card ANIMA would otherwise generate from the mod's own data.

See [CONTRIBUTING.md](../CONTRIBUTING.md) for the format and the rules.
